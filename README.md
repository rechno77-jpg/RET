# MVP سامانه سرمایه‌گذاری

این پروژه یک اسکلت فنی اولیه برای مدل زیر است:

- واحد پول: تومان
- حداقل سرمایه‌گذاری: ۵۰٬۰۰۰ تومان
- نرخ ماهانه: ۵٪
- سود به صورت روزانه به کیف پول افزوده می‌شود
- سود کیف پول قابل درخواست برداشت است
- اصل سرمایه نیز هر زمان کاربر بخواهد، به‌صورت کامل یا بخشی قابل برداشت است
- وقتی کاربر اصل سرمایه را برای برداشت رزرو می‌کند، همان بخش فوراً از سرمایه فعال کم می‌شود تا از روز بعد برای آن سود محاسبه نشود
- برداشت به شکل «درخواست برداشت» ثبت می‌شود و تا زمان پرداخت توسط مدیر، وضعیت دارد

## فرمول فعلی سود روزانه

در این MVP برای شفافیت، ماه ۳۰ روزه در نظر گرفته شده:

`سود روزانه = اصل سرمایه × ۵٪ ÷ ۳۰`

مثال:
- اصل سرمایه: ۱٬۰۰۰٬۰۰۰ تومان
- سود ماهانه: ۵۰٬۰۰۰ تومان
- سود روزانه تقریبی: ۱٬۶۶۶ تومان

## نکته مهم

این کد به‌تنهایی برای دریافت واقعی پول مردم در محیط عملیاتی کافی نیست. قبل از لانچ عمومی باید:
- مدل حقوقی/قراردادی و مجوزهای لازم بررسی شود.
- احراز هویت، ورود امن، OTP، محدودیت برداشت، ثبت لاگ، ضدتقلب و کنترل‌های مالی اضافه شود.
- اتصال درگاه پرداخت و تسویه فقط با سرویس‌دهنده مجاز انجام شود.
- محاسبه سود و شرایط فسخ/برداشت اصل سرمایه در قرارداد دقیقاً با منطق نرم‌افزار یکسان باشد.

## اجرا

1. PostgreSQL راه‌اندازی کن.
2. فایل `.env.example` را به `.env` کپی کن.
3. سپس:

```bash
npm install
npx prisma generate
npx prisma migrate dev --name init
npm run dev
```

## Cron سود روزانه

هر روز یک بار:

`POST /api/cron/accrue-daily-profit`

با هدر:

`Authorization: Bearer <CRON_SECRET>`

## ادامه پیشنهادی توسعه

نسخه بعدی باید شامل این بخش‌ها باشد:
- ثبت‌نام/ورود با موبایل و OTP
- احراز هویت
- داشبورد سرمایه‌گذار
- نمایش اصل سرمایه، سود امروز، سود کل و موجودی قابل برداشت
- پنل مدیریت
- تأیید/رد/پرداخت درخواست برداشت
- درگاه پرداخت
- قرارداد دیجیتال و ثبت پذیرش شرایط
- گزارش مالی و لاگ حسابرسی
## برداشت اصل سرمایه

مسیر:

`POST /api/principal-withdrawals`

نمونه ورودی:

```json
{
  "userId": "USER_ID",
  "investmentId": "INVESTMENT_ID",
  "amountToman": 500000,
  "cardNumber": "..."
}
```

- برداشت کامل: اگر کل اصل سرمایه درخواست شود، سرمایه‌گذاری `CLOSED` می‌شود.
- برداشت بخشی: مبلغ از اصل سرمایه کم می‌شود و فقط مانده سرمایه از روز بعد سود می‌گیرد.
- اگر درخواست برداشت اصل سرمایه توسط مدیر رد شود، مبلغ به اصل سرمایه برمی‌گردد.
## دریافت روزانه سود

در نسخه جدید، سود روزانه فقط با اقدام کاربر دریافت می‌شود:

`POST /api/profit/claim`

- هر کاربر فقط یک بار در هر روز می‌تواند سود همان روز را دریافت کند.
- سود بعد از دریافت به کیف پول اضافه می‌شود.
- روزهایی که کاربر دریافت نکند، به‌صورت خودکار سودی به کیف پول اضافه نمی‌شود.

## دعوت دوستان

- هر کاربر یک `referralCode` یکتا دارد.
- فقط دعوت مستقیم (یک سطح) پشتیبانی می‌شود.
- معرف معادل ۲٪ از سود روزانه‌ای که دوستش دریافت کرده، پاداش می‌گیرد.
- این ۲٪ از سود دوست کم نمی‌شود و به‌عنوان هزینه/پاداش جداگانه از طرف پلتفرم ثبت می‌شود.
- برای جلوگیری از ساختارهای هرمی، زیرمجموعه چندسطحی در این نسخه وجود ندارد.
